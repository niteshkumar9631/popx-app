## Installation

Clone the repository:

```bash
git clone https://github.com/niteshkumar9631/popx-app.git
```

Move into the project directory:

```bash
cd popx-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
